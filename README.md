### I like things in order. I don't much care how messy the road there is.

That's most of me, really. Things should be neat, tidy and work exactly the way
I intended. Getting there is usually a bit wild, and that's fine.

I build to understand how things work. Then I automate them so I never have to
think about them again. I care more about the underpinnings than the finished
surface, which is probably obvious to anyone who has worked with me.

I'd be doing this unpaid. I mostly already am, it's what the weekends look
like. I ran my own studio for a while and built products for myself and for
customers, and the best part was choosing what to work on and how.

What I actually want is for someone else to use the thing. Seeing something I
built save another person time, or make something possible that wasn't before,
that's the dream. The rest is just me enjoying myself.

What I won't do is monotony. Copy paste work, the same page for the fifth time.
I've done plenty of it and it's crushing. Give me something that needs a new
angle and I'm happy.

Life first, things second. The things just have to behave.

### Tools

Things that stood in my way, rebuilt until they got out of it.

**[mdql](https://github.com/Kwickell/mdql)**
Quick Look for Markdown on macOS. Press space on a `.md` file in Finder and
read it as a document instead of as source. Tables, syntax highlighting,
Mermaid diagrams, maths, callouts and wiki links. It never touches the network,
which took more work than the rendering did.

More will land here. There's a window manager I keep muttering at.
