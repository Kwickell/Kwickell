### Building

**[mdql](https://github.com/Kwickell/mdql)**

Quick Look for Markdown on macOS. Press space on a `.md` file in Finder and read the document instead of the source. Tables, syntax highlighting, Mermaid diagrams, maths and callouts. It never touches the network, which took more work than the rendering did.

**Draki**

A dragon that lives on my son's phone, his laptop and the panels on our walls at home. Somewhere between a tamagotchi, a day planner and a reward system. It follows him around, tells him what's coming, and makes a proper fuss when he gets it right.

I've been building it far too long. The code was never the hard part, finding the evenings is.

### How I work

I build things to understand how they work, then automate them so I never have to think about them again.

Underpinnings before surface, every time.

Anything standing in my way gets rebuilt until it gets out of it. mdql is one of those. There's a window manager I keep muttering at.

The dream is someone else using the thing. Saving them an hour, or making something possible that wasn't before.

Monotony is the one thing I won't do. Copy paste work is crushing. Give me something that needs a new angle and I'm happy.

Life first, things second. The things just have to behave.
